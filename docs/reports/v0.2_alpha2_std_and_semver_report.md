### 2.2 Key Empirical Findings
1. **White-Box C Library Bridging (`std::ffi::c_abi` + `spindle bindgen-c`) Eliminates Black-Box `import c "header.h"` and Achieves $\text{TCR}_{\text{impl}} = 0.1786$**:
   * In traditional languages, directly importing C headers turns external dependencies into un-auditable black boxes; furthermore, Rust still lacks native C99 bitfields (requiring manual mask-and-shift boilerplate `(self.packed_word0 >> 4) & 0xF` inside `#[repr(C)]` structs) and requires wrapping every `union` field read in `unsafe { ... }`;
   * Jenny natively supports 1:1 physically aligned `@repr(C) struct` bitfields (`@bits(N)`), `@repr(C) union` shared memory views, and `@extern_c("c_symbol")` white-box bindings. `spindle bindgen-c` automatically synthesizes bit-width invariants `invariant self.field >= 0 && self.field <= (2^N - 1)`, allowing `std::ffi::c_abi.jn` to require just **147 tokens** (vs. Rust's **823 tokens**, an **82.14%** reduction) while verifying `c_sizeof_frame(hdr) == 8` and `c_sizeof_union(u) == 4` at runtime with 100% accuracy!
2. **Layer-0 Runtime Intrinsics White-Boxing (`std::rt::intrinsics`) & Live Catch by `E0510` Static Guard**:
   * By introducing [`std/rt/intrinsics.jni`](../../std/rt/intrinsics.jni), all 22 C runtime primitives previously scattered across `jenny_rt.h` are brought under Jenny's formal contract system (with `40` `requires`/`ensures` contracts and `effects [Mutate, AllocNative]` annotations);
   * When `E0510_UNDECLARED_RT_INTRINSIC` static scanning was first enabled in `spindle audit`, it immediately caught a subtle boundary violation where `contains_key` in `std/collections/hash_map.jn` bypassed `RawBuf.read_at` to call `jn_raw_get(self.buf.ptr, ...)` directly. Refactoring it to call the contract-protected `self.buf.read_at(...)!` closed the layered white-box loop across all 15 standard library modules.
3. **Three-Tier Orthogonal `Formattable` Trait Union + 3-Branch Procedural `@spin` Template Expansion + First-Class Tuple-Preserving `.spun` Materialization (`std::str::fmt`)**:
   * By defining `pub type Formattable = FmtInto | ToStr | (FmtSpecInto, FmtSpec, ...i64)`, `format_with` in [`std/str/fmt.jn`](../../std/str/fmt.jn) completely eliminates hardcoded per-type branching over primitives like `str`, `String`, `bool`, and `i64`, requiring only **3 orthogonal trait branches** (tuple `(val_item, spec, ...params)`, `FmtInto`, and `ToStr`);
   * The materialized `.spun/std_str_fmt.spun.jn` and the global deduplication cache `.jenny-cache/spin/format_with__spin_<hash>.spun.jn` preserve first-class tuple parameter types (e.g., `_arg3: (i64, FmtSpec, i64)`) and destructure them inside the function body via `_arg3.0`, `_arg3.1`, `_arg3.2`—supporting storing a tuple in a variable `val hex_item = (48879, FmtSpec.HexLower, 4)` and passing it directly into `str::format("id=", -42, ",hex=0x", hex_item)`!

## 3. Empirical Verification of `Spindle` Phase 3, Phase 4, `bindgen-c` & `pack`/`decompile`

### 3.1 Phase 3: `Tapestry.lock` Dual-Hash Lockfile (`spindle lock`)
[`std/Tapestry.lock`](../../std/Tapestry.lock) generates separate **Interface Contract Merkle Roots (`package_jni_abi_merkle_root`)** and **Implementation Code Merkle Roots (`package_jn_impl_merkle_root`)** across all 15 standard library modules:
* Whenever any dependency optimizes internal algorithms in `.jn` without altering its `.jni` contracts, `jni_abi_hash` remains 100% invariant, allowing downstream packages to skip re-typechecking via the `.jni` header firewall short-circuit.

### 3.2 Phase 3: Contract-Subtyping Semantic Version Upgrade Verification (`spindle semver-check`)
Traditional package managers (Cargo / npm / Go Modules) rely on human-assigned nominal SemVer numbers, frequently smuggling implicit precondition strengthenings or unauthorized side effects into `Patch` releases. `spindle semver-check` enforces behavioral subtyping grounded in Hoare Logic:
$$E_{\text{new}} \subseteq E_{\text{old}} \;\land\; (\text{Req}_{\text{old}} \implies \text{Req}_{\text{new}}) \;\land\; (\text{Ens}_{\text{new}} \implies \text{Ens}_{\text{old}})$$
Combined with differential `@example` execution, it verified 1 safe hot-swap scenario and intercepted 4 breaking upgrade mutations on `std::codec::varint`:

| Case / Mutation ID | Upgrade Scenario Description | `spindle semver-check` Classification | Triggered Diagnostic Code | Result |
| :--- | :--- | :---: | :--- | :---: |
| **`SAFE-HOT-SWAP`** | Refactor internal negative-number arithmetic in `zigzag_encode` inside `varint.jn` (`.jni` unchanged) | **`SAFE_PATCH_HOT_SWAP`** (`jni_abi_unchanged = true`) | None (`compatible = true`) | ✅ Approved for zero-rebuild hot-swap |
| **`MUT-SEMVER-E0506`** | Upgraded version adds `effects [Net]` to `VarintStream.encode_u64` | **`BREAKING_REJECTED`** | `E0506_SEMVER_EFFECT_EXPANSION` | ✅ 100% Intercepted |
| **`MUT-SEMVER-E0507`** | Upgraded version strengthens `requires val >= 0` to `requires val >= 10` (breaking callers passing `0..9`) | **`BREAKING_REJECTED`** | `E0507_SEMVER_STRENGTHENED_REQUIRES` | ✅ 100% Intercepted |
| **`MUT-SEMVER-E0508`** | Upgraded version drops postcondition guarantee `&& result >= 0` on `decode_u64` | **`BREAKING_REJECTED`** | `E0508_SEMVER_WEAKENED_ENSURES` | ✅ 100% Intercepted |
| **`MUT-SEMVER-E0509`** | Upgraded version keeps `.jni` unchanged but introduces `val * 2 + 1` arithmetic regression in `zigzag_encode` | **`BREAKING_REJECTED`** | `E0509_SEMVER_BEHAVIORAL_REGRESSION` | ✅ 100% Intercepted |

### 3.3 Phase 4: Pure `.jni` Blueprint + Unified AST Archive Distribution (`spindle pack`), On-Demand Lossless Decompilation (`spindle decompile`) & Blueprint Synthesis (`spindle synthesize`)
1. **`spindle pack` (Zero `.jn` Source Files and Zero `.spun` Files in Distribution)**:
   * Precompiles and packages the `.jn` implementations of all 15 modules into a single canonical AST archive [`std/lib/std.jnast`](../../std/lib/std.jnast) (`147,000` bytes, `sha256: 33ff0ed800af8f6c`). The distribution manifest contains only `Tapestry.toml`, `Tapestry.lock`, the 15 read-only `.jni` blueprints, and `lib/std.jnast`;
2. **`spindle decompile` (15/15 Modules 100% Lossless AST Decompilation Round-Trip Verification)**:
   * Reconstructs formatted Jenny v2.0 `.jn` source code on demand for all 15 modules from `std/lib/std.jnast`. Across **all 15/15 modules, `original_ast_sha256 == decompiled_ast_sha256` (`all_roundtrip_exact = true`)**, and the decompiled `std::str::fmt` source passes C99 `-O3` compilation and `@example` execution directly;
3. **`spindle synthesize` (Direct `.jn` Implementation Synthesis from `.jni` Contracts)**:
   * Reading only the struct definitions and `ensures` contract equations in [`std/str/str_view.jni`](../../std/str/str_view.jni) (including `slice_str` zero-copy extraction), synthesizes the complete `.jn` implementation of `StrSliceView` (`226` tokens), passing C99 compilation and all contract tests at 100%.
